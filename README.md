# Cancionero MV

Cancionero digital para Voluntarios en el servicio misionero de la Iglesia Adventista del Séptimo Día: cancionero, himnario adventista y cantos de campamento en un solo lugar, con acordes, tonalidad, tablatura y todo lo necesario para tocar o dirigir una canción.

🔗 **App en línea:** https://hagigliotti.github.io/cancionero/index.html

## ¿Qué es?

Una PWA (Progressive Web App) hecha en JavaScript puro, sin frameworks ni paso de build: buscador de canciones por título, letra, autor o etiqueta; acordes con diagramas de piano, guitarra, bajo y ukelele; transposición de tonalidad; modo proyector para el culto; metrónomo y afinador; y listas propias exportables. Funciona sin conexión una vez instalada.

Ver la sección "Información de la app" dentro de la aplicación para la guía completa de funcionalidades.

## Idiomas

Español, Inglés, Guaraní, Italiano y Portugués, con banderas para cambiar el idioma de cada canción individualmente.
